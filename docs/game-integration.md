# Game integration

There is no supported Hogwarts Legacy client integration in this repository. `IGameIntegration` and `ICharacterService` define seams only. Player synchronization, spell casting, flying, animations, NPC interaction, and a dedicated game server are unavailable. A real integration must use a compatible lawful project, verify its license and technical compatibility, and must not redistribute proprietary game assets or bypass ownership, platform authentication, anti-cheat, DRM, or security controls.
