# Lua scripting

Put server Lua files in a resource directory and list them with `server_script` in `fxmanifest.lua`. Each resource runs in a separate worker process with a Lua 5.4 state shared by that resource's server/shared scripts. Available APIs include `RegisterCommand`, `RegisterNetEvent`, `AddEventHandler`, `TriggerEvent`, and `TriggerClientEvent`. Client-to-server events must be registered with `RegisterNetEvent(name)`; their handlers receive the server-issued player session ID and authenticated display name, then the client payload. Server-to-client events use `TriggerClientEvent(name, playerId, ...arguments)`. `TriggerServerEvent` is a client-side API and remains unavailable in server resources. Client execution, Wait scheduling, character/house APIs, and persistence are not implemented yet.

Local events are scoped to a resource worker; server-raised events are relayed between workers by Core. Client-originated network events are allowlisted per resource and dispatched only to the resources that registered them. Server commands are registered with the host and routed back to the owning worker.

The runtime removes `os`, `io`, `package`, `debug`, `coroutine`, `dofile`, `loadfile`, `require`, `collectgarbage`, `pcall`, `xpcall`, and the NLua CLR bridge before executing resource code. A debug count hook enforces a 2 million instruction budget per script call by default, and script source is limited to 256 KiB. Windows workers have a hard 512 MiB Job Object memory limit and a 50% CPU-rate cap. Linux workers have a 768 MiB `RLIMIT_DATA` cap and a 10 CPU-second budget per request; the parent also applies a 30 second wall-clock timeout and monitors 512 MiB private memory on both platforms. Workers run as the server's OS user, so there is no OS sandbox or filesystem/network ACL. Removing protected calls is intentional so scripts cannot catch and ignore the instruction-budget hook error.

The server accepts WebSocket sessions at `/connect`. Remote endpoints require HTTPS/WSS. The first message authenticates with a short-lived one-time join ticket; the current local console can issue bootstrap tickets, but a trusted account provider must be integrated before exposing the server publicly. The launcher does not yet obtain tickets or connect a game client.
