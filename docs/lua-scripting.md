# Lua scripting

Put server Lua files in a resource directory and list them with `server_script` in `fxmanifest.lua`. Each file receives its own restricted NLua/KeraLua state running native Lua 5.4. Available API registration includes `RegisterCommand`, `RegisterNetEvent`, `AddEventHandler`, `TriggerEvent`, `TriggerClientEvent`, `TriggerServerEvent`, and `GetPlayerName`. The network calls explicitly fail because no network adapter is installed. Client execution, Wait scheduling, character/house APIs, and persistence are not implemented yet.

The runtime removes `os`, `io`, `package`, `debug`, `coroutine`, `dofile`, `loadfile`, `require`, `collectgarbage`, `pcall`, `xpcall`, and the NLua CLR bridge before executing resource code. A debug count hook enforces a configurable instruction budget (2 million by default), and script source is limited to 256 KiB. Resource callbacks execute within the same budget and state lock. This is not process isolation and has no strict memory ceiling; use trusted scripts only until worker process isolation is added. Removing protected calls is intentional so scripts cannot catch and ignore the budget hook error.
