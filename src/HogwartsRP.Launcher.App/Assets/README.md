# Launcher artwork assets

The launcher loads these optional files from this directory:

- `HogwartsRP.ico` — Windows executable and window icon, based on the selected Moonlit Crest artwork.
- `HogwartsRP-Splash.jpg` — startup splash artwork, based on “Hogwarts RP: A New Chapter”.

Copy the matching files from the separately supplied `HogwartsRP_Launcher_Artwork.zip` into this directory. The project file includes each asset when present and copies it beside the application. If either file is absent, the launcher uses a text fallback and continues to start.
